HD path walker — next index, unique addresses.

## Features

- MULTI path m/44'/0'/0'
- Deterministic digest (stdlib, no crates)
- Vault + account derive
- cargo test covers keys and wallet

## Prerequisites

- Rust 1.75+
- Git

## Getting Started

```bash
git clone <repo-url>
cd hdpath-walk
cargo build --release
./target/release/hdpath-walk --help
```

## Tests

```bash
cargo test
```
